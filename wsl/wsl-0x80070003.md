# Troubleshooting WSL2 Initialization & Error 0x80070003

## Problem Statement
When attempting to launch a freshly installed Ubuntu distribution on Windows via WSL2, the terminal failed during `WslRegisterDistribution` with error `0x80070003` ("The system cannot find the path specified") and closed immediately upon launch.

## Root Cause Analysis
Although CPU virtualization and `Virtual Machine Platform` were enabled in Windows settings, the core `Windows Subsystem for Linux` optional feature driver was disabled in the operating system kernel settings. This prevented the Microsoft Store package from creating and linking its root filesystem directory.

## Resolution Workflow
1. Opened **Control Panel** > **Programs and Features** > **Turn Windows features on or off**.
2. Confirmed `Virtual Machine Platform` was enabled.
3. Located and checked the box for `Windows Subsystem for Linux`.
4. Clicked **OK** and performed a full system reboot to load the kernel drivers.
5. Launched **Ubuntu** from the Start Menu; initialization completed cleanly and requested initial UNIX account credentials.

## My Key Takeaway
Both `Virtual Machine Platform` (for hypervisor support) and `Windows Subsystem for Linux` (for WSL driver bindings) must be active simultaneously for Linux distributions to register correctly.
